# 신박살림 아이템 발굴 도구 (미니 튜브렌즈)

키워드로 유튜브 영상을 검색해서 "채널 규모 대비 얼마나 잘 터졌는지"
점수를 매기고, 점수 높은 순으로 CSV + HTML 리포트를 만들어주는
개인용 스크립트입니다. 골든파인더/튜브렌즈의 "영상 소싱 + 영상 점수"
기능만 뽑아서 무료로 직접 만든 버전이라고 보시면 됩니다.

## 1. 준비물 - 유튜브 API 키 발급 (무료)

1. https://console.cloud.google.com 접속 (구글 계정 로그인)
2. 상단에서 새 프로젝트 만들기 (이름은 아무거나, 예: `item-finder`)
3. 좌측 메뉴 → "API 및 서비스" → "라이브러리" 에서 `YouTube Data API v3` 검색 → **사용 설정**
4. "API 및 서비스" → "사용자 인증 정보" → "+사용자 인증 정보 만들기" → **API 키** 선택
5. 생성된 키를 복사해두기 (예: `AIzaSy...`)

> 무료 할당량: 하루 10,000 유닛. 검색 1회(키워드 1개)당 약 100~200유닛
> 소모되므로, 하루에 키워드 30~50개 정도까지는 여유 있게 쓸 수 있습니다.

## 2. 설치

```bash
pip install -r requirements.txt
```

## 3. 실행

API 키를 매번 입력하기 번거로우면 환경변수로 등록해두세요.

```bash
# Mac/Linux
export YOUTUBE_API_KEY="여기에_API_키_붙여넣기"

# Windows (PowerShell)
$env:YOUTUBE_API_KEY="여기에_API_키_붙여넣기"
```

그 다음 실행:

```bash
python youtube_item_finder.py --keywords "신박한 아이템" "살림 꿀템" "혼자 사는 살림템" --shorts-only
```

옵션:

| 옵션 | 설명 | 기본값 |
|---|---|---|
| `--keywords` | 검색할 키워드 (여러 개 가능, 필수) | - |
| `--max-results` | 키워드당 최대 수집 개수 | 30 |
| `--days` | 최근 N일 이내 영상만 검색 | 30 |
| `--shorts-only` | 쇼츠(짧은 영상)만 필터링 | 끔 |
| `--shorts-max-seconds` | 쇼츠 판단 기준 길이(초) | 180 |
| `--api-key` | API 키 직접 지정 (환경변수 대신) | - |
| `--out-dir` | 결과 저장 폴더 | reports |

실행이 끝나면 `reports/` 폴더에 `report_날짜시간.csv`와
`report_날짜시간.html`이 생깁니다. **html 파일을 더블클릭해서 브라우저로
열어보면 표 형태로 한눈에 확인할 수 있습니다** (영상점수 5점 이상은
주황색으로 하이라이트됩니다).

## 4. "영상 점수"는 어떻게 계산되나요?

```
영상 점수 = (조회수 ÷ 구독자수) × 0.7 + (참여율 × 100) × 0.3
```

- **조회수 ÷ 구독자수**: 구독자 8천 명 채널의 영상이 50만 뷰가 나왔다면
  배수가 62.5로, "구독자 대비 훨씬 많이 퍼졌다"는 뜻입니다. 즉 알고리즘을
  타고 신규 유입이 많이 됐다는 신호로 봅니다.
- **참여율**: (좋아요+댓글) ÷ 조회수. 단순 노출이 아니라 실제로 사람들이
  반응했는지를 봅니다.
- 가중치(0.7 / 0.3)는 `youtube_item_finder.py`의
  `calculate_video_score()` 함수에서 직접 조정할 수 있습니다.
- 구독자 수를 비공개로 설정한 채널은 배수를 계산할 수 없어 점수가
  `-`로 표시됩니다 (참여율만 참고).

## 5. 웹 브라우저에서 쓰고 싶다면 (Streamlit 웹 앱 버전)

터미널 없이 브라우저에서 키워드 입력하고 결과를 표로 바로 보고 싶다면
`streamlit_app.py`를 쓰세요. 로컬에서 먼저 테스트:

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

실행하면 자동으로 브라우저가 열리고 `http://localhost:8501`에서
웹앱처럼 쓸 수 있습니다. 인터넷 어디서든 접속 가능한 주소가 필요하면
`DEPLOY.md`를 참고해 GitHub + Streamlit Community Cloud에 무료로
배포하세요.

## 6. AI 영상 분석 (선택 기능)

카드형 화면에서 영상마다 있는 **"🔍 분석"** 버튼을 누르면, 별도 창(모달)이
뜨면서 왼쪽엔 원본 쇼츠 영상, 오른쪽엔 AI 분석 결과가 나란히 표시됩니다.
분석 내용이 길어도 오른쪽 영역 안에서만 스크롤되니 페이지 전체가 늘어지지
않습니다.

분석 항목:

- 제품정보 / 추천 검색어 (🇰🇷 한국어 + 🇨🇳 중국어)
- 후킹 방식 (시작 멘트, 기법)
- 떡상요인
- 영상 흐름 (구간별 전개)
- CTA
- **관련 영상 더 찾기 (유튜브)** 버튼 — 분석에서 나온 한국어 키워드로
  유튜브에서 비슷한 영상을 추가로 찾아줍니다.

**필요한 것: Gemini API 키 (무료)**

1. https://aistudio.google.com/app/apikey 접속 (구글 계정 로그인)
2. "Create API key" 클릭 → 키 복사
3. 사이드바의 "Gemini API 키" 입력란에 붙여넣기 (또는 Streamlit Cloud
   Secrets에 `GEMINI_API_KEY = "키값"` 으로 등록)

이 키가 없어도 검색·수집·카드/표 보기는 그대로 다 됩니다. **"🔍 분석"
버튼만** Gemini 키가 있어야 작동합니다. "관련 영상 더 찾기"는 유튜브
API 키만 있으면 되고, Gemini 키와는 무관합니다.

**인스타그램은 지원하지 않습니다.** 인스타그램은 외부 개발자에게 공개된
검색 API가 없어서, 유튜브처럼 자동으로 관련 영상을 찾아주는 기능을
만들 수 없습니다. 유튜브만 지원합니다.

**알아두면 좋은 점**

- 자막은 유튜브가 화면에 공개적으로 보여주는 자막을 가져오는 방식이라,
  자막이 아예 없는 영상은 분석 정확도가 떨어질 수 있습니다 (이 경우
  제목만으로 추정 분석하고, 화면에 "자막을 가져오지 못했다"는 안내가
  같이 표시됩니다).
- Gemini 무료 티어의 모델별 한도는 2026년 들어 여러 번 바뀌었습니다.
  분석 버튼을 눌렀을 때 오류가 나거나 너무 느리면, `video_analyzer.py`
  상단의 `DEFAULT_MODEL` 값을 aistudio.google.com에서 확인한 현재
  무료 한도가 넉넉한 모델 이름으로 바꿔보세요.

## 8. 주의할 점

- 이 스크립트는 유튜브 공식 API만 사용하므로 약관 위반 걱정 없이 쓸 수
  있습니다.
- 인스타그램·샤오홍슈는 공식 API로 이런 검색이 되지 않아 이 스크립트
  범위에는 포함하지 않았습니다 (별도 수동 루틴 권장).
- API 키는 절대 깃허브 등 외부에 공개로 올리지 마세요.
